# A Bug-Eyed Fish Named Charles

Shawn Fitzpatrick and his family in the *Weeping Water Republican* and the *Plattsmouth Journal*, told through hand-transcribed clippings.

- `index.html`: the page. Each `<figure data-clip="id">` is filled from `data/clips.json`.
- `clips/`: cleaned newspaper images.
- `js/config.js`: reader memories settings. This site shares its Google Form and Sheet with the flood and Halloween sites; its chapter IDs start with `sf-`. Only rows marked approved in the Sheet appear on the site.

Static site, no build step. Serve with any web server, or host free on GitHub Pages.
